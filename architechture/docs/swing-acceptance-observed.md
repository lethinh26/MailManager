## 3. Lỗi nguồn đã sửa từ quan sát (chưa chạy test/build Client)

1. **M30 first Save wrong start dir**: `FileUtil.prepareAttachmentDirectory` tạo mailbox directory bằng Files.createDirectories trước khi mở chooser, MainFrame xử lý lỗi không fallback âm thầm; ComposeDialog mở chooser tại configured download dir, tạo thư mục nếu cần, báo lỗi nếu không mở được. Test `AcceptanceRegressionTest#firstSaveChooserDirectoryExistsUnderConfiguredRoot`: fresh dir, đúng path, không overwrite existing. Quan sát thực tế chỉ chứng minh lỗi + workaround tạo folder fixture; bản sửa chưa chạy.
2. **M16 attachment chip clipping**: `Theme.horizontalChipScroll` dùng JScrollPane horizontal scrollbar always, vertical never; MainFrame detail footer và Compose chips chuyển vào viewport để mọi chip tiếp cận được, thay vì FlowLayout bị wrap rồi clip trong footer cao một hàng. Test `UiLayoutRegressionTest#attachmentStripKeepsAllChipsReachableAtNarrowWidth`: 3 chips, width 260, view scroll được tới chip cuối, same row, không clip dọc. Cần build/test/quan sát lại bản sửa.
3. **Tooling safety/IPC**: launcher source-mode không Gradle, explicit config/user.home fixture; manifest private, guard server PID; chooser whitelist action/path canonical, không enumerate personal shell listing hoặc chụp chooser; temp credential dialog redacted, no clipboard; per-request response avoids replacement race, bounded waits/lease, close only own JVM. Parser PowerShell OK, console đã compile lightweight và mở thực tế; cuối cùng có thêm safety guard sau lần chạy, chưa re-run bản helper cuối. Không thay đổi production security.
